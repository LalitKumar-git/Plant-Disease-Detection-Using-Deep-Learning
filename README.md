# Plant Disease Detection Using CNN and Deep Learning
### Final-Year BTech Computer Science & Agricultural Engineering Project

## Technologies
- Python 3.10+
- Flask
- TensorFlow / Keras 2.x
- MobileNetV2
- SQLite
- HTML5 / CSS3 / JavaScript

## Quick Start on macOS:
```bash
cd plant-disease-detection
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python database/db_setup.py
python sample_test_procedure.py
python app.py
```

## Trained Weights Location:
Place your trained weights file at:
```text
models/plant_disease_mobilenetv2.h5
```
